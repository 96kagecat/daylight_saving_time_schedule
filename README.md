# サマータイム切り替わりタイムスケジュール

サマータイムの開始・終了日時と、前後のタイムスケジュールを確認できるWebツールです。

## 公開ページ

https://96kagecat.github.io/daylight_saving_time_schedule/

## 使い方

- ページへアクセスしてください。
- 表示対象年を選択してください。現在から2年先まで選択可能です。初期表示時は現在年が表示されます。
- サマータイムの開始・終了日時を確認できます。
- 「タイムスケジュール」を開くと、関連するスケジュールを確認できます。
- 表示時刻は日本時間を基準にしています。
